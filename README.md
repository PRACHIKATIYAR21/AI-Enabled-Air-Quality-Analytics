
# AI Enabled Unified Real-Time Air Quality Analytics

An AI-powered air quality monitoring and analytics system for classroom environments.

## Features
- Real-time sensor monitoring using ESP32
- ThingSpeak cloud integration
- Air quality classification using Decision Tree
- Estimated AQI calculation using PM2.5 and PM10
- Smart alerts and precaution recommendations
- Gemini AI-powered assistant

## Sensors Used
- DHT11
- BH1750
- MQ135
- PMS5003

## Technologies Used
- Python
- Flask
- Machine Learning
- HTML, CSS, JavaScript
- ThingSpeak
- Gemini API

## Installation

Install dependencies:

pip install -r requirements.txt

Configure your environment variables in a local .env file.

Run the application:

python app.py
